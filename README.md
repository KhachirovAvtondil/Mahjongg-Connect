# Mahjongg-Connect(Маджонг с волновым алгоритмом на клетчатом поле)
   


# Идея игры

Игра будет написана для платформы Яндекс игры при помощи волнового алгоритма.
Название: Mahjongg  Connect Animals/ Маджонг Животные
Жанр: Каузальный/Головоломка
Концепция: Классические китайские иероглифы  будут заменены на изображения различных животных.
Всего будет 3 главы(мира) по 10 уровней у которых будут по 20 уникальных костяшек/тайлов с изображениями соответствующих представителей животного мира.

1. Мир домашних питомцев

2. Мир обитателей леса.

3. Подводный мир.


# Правила игры:
1. За один ход можно убрать две одинаковые кости (тайлы) с изображениями животных.
2. Игрок становится победителем, когда полностью очищает поле от всех костей. Если доступных пар не осталось - кости будут автоматически перемешаны.
3. На прохождение уровня дается время, количество которого зависит от сложности. По истечении времени игрок считается проигравшим.

# Оформление Меню:
Первое окно станет главным меню
оно будет содержать три кнопки в данном порядке.
1. Играть/Продолжить
2. Уровни
3. Настройки

   Кнопка "играть/продолжить": игра сразу перебрасывает на первый уровень, если вы новичок или же на последний открытый игроком уровень, на котором он остановился.
   
   Кнопка "Уровни": открывает экран с главами и их уровнями, где игрок сможет выбрать любой понравившийся ему уровень или главу и пройти их повторно.
   так же на экране "Уровни" будет кнопки "Достижения" (Изображение кубка), "Подсказки" (лупа) и "Настройки" (Шестеренка).

   Экран настройки:
   1. включить/выключить музыку
   2. включить/отключить звуковые эффекты
   3. Ползунок для настройки громкости звука.
   4. Обнулить прогресс.
  
   **Экран достижения:**
  панель, содержащая список достижений
   например. "Новичок" пройти уровень 1, "Мегамозг" пройти игру, не используя подсказок.

  **Экран Подсказок:**
   В начале игры у игрока будет 5 подсказок. Потратив все, он сможет восполнить их, посмотрев рекламу(+3 за  рекламу).



   # Логика игры и Оформление Уровней.
   Интерфейс игрового экрана будет содержать само игровое поле, которое занимает около 90% самого экрана, А поверх него служебные кнопки.

   **Кнопки:**
   
   Левый Верхний Угол:
   
  Кнопка "Выбрать Уровень" (стрелка влево). Перебрасывает игрока на экран "Уровни"
  Кнопка "Выйти в главное меню" (Значок дома). Выкидывает игрока в самое первое окно главного меню.
   Кнопка "Подсказки" (Лупа).  ((Открывает экран(панель) Подсказок. В начале игры у игрока будет 5 подсказок. Потратив все, он сможет восполнить их, посмотрев рекламу(+3 за  рекламу)).

   Правый Верхний Угол
   Кнопка "Настройки" (Шестеренка). Все тоже самое, что было сказано ранее. манипуляции с музыкой и звуковыми эффектами, обнуление прогресса.
   Кнопка "Достижения" (Кубок). Открывает панель со всеми достижениями.

 **Оформление уровня:**
   
   Верх Середина:

   "Глава" + "номер главы".
   Под главой "номер уровня" + "Уровень"
   Под "номер уровня" + "Уровень" устанавливается таймер обратного отсчета.

   Поле после завершения уровня:

   В случае победы вылезет окно:
   Зелеными буквами Поздравление. ниже кнопки "Меню", "Достижения", "Следующий уровень".

   В случае поражения вылезет окно:
   Красными буквами Время истекло. ниже кнопки "Меню" "Достижения", "Повторить".

   **Игровая Механика:**
   1. Игровое поле является клетчатым и представляет собой матрицу (АхБ). Адаптация будет под ПК и мобильное устройство.
   2. На игровом поле(сетке) будут пустые квадраты по котором можно будет провести "воображаемую линию" от одного тайла к ему подобному.
   3.Согласно принципу волнового алгоритма, на основе которого будет написана игра, пара убирается только в том случае, если воображаемая линия между двумя тайлами делает не более двух поворотов на 90 градусов. Когда путь соответствует условию алгоритма, при нажатии на две парные костяшки, на поле появляется линия, показывающая минимальный путь от костяшки к ее паре. 
   4. Задача игры полностью очистить клетчатое поле от всех тайлов/костяшек пока не истекло время. Если доступных пар не остается, игра автоматически перемешает тайлы на поле.
